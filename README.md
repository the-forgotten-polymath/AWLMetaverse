# AWL Metaverse

A unified digital services & enterprise infrastructure platform engineered in Next.js, TypeScript, and Tailwind CSS.

## Overview
- **Next.js 14 App Router** architecture with responsive, dark-mode design system.
- **Enterprise Capabilities**: AI & Autonomous Workflows, Custom ERP/CRM/LMS Engineering, High-Velocity Web & Mobile Apps, Performance Marketing.
- **Dual Innovation Hubs**: Jind (HQ) & Chandigarh.

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
